# Adaptive Repository Learning Engine

**Feature**: "Explain This Repository Like I'm New Here"

## 1. Core Principle: Shared Evidence, Adaptive Tone
All experience tiers evaluate the exact same verified AST graph, file classification, and architecture metrics. Switching levels changes the abstraction layer, analogies, and focus without triggering reindexing.

## 2. Experience Levels

### Beginner Mode
- **Audience**: Students, junior engineers, or developers learning a new ecosystem.
- **Content**: Plain English, conceptual analogies (e.g., airport terminals, workshops), file roles, entry-point explanations, step-by-step contribution guides, and comprehension checks.

### Developer Mode
- **Audience**: Mid-level software engineers looking to contribute or understand codebase mechanics.
- **Content**: Layered architecture breakdowns, request-to-database routing, core service contracts, test commands, and dependency structure.

### Senior Engineer Mode
- **Audience**: Staff/Principal engineers and software architects.
- **Content**: Structural coupling (Afferent $C_a$ vs Efferent $C_e$ coupling), Robert C. Martin's instability metric ($I = \frac{C_e}{C_a + C_e}$), dependency cycles, Tarjan's Strongly Connected Components (SCC), PageRank centrality hotspots, and refactoring recommendations.
